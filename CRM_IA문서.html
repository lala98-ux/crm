고객 목록 클릭 진입
10어드민고객 관리세그먼트 관리---신규·관심·구매준비·기존고객·이탈위험·휴면 등 세그먼트 생성·수정·삭제. 각 세그먼트의 편입 조건(스코어 범위, 구매 이력, 접속 주기 등) 설정. 조건 설정 즉시 해당 고객 수 미리보기 표시. 세그먼트별 고객 목록 바로가기 제공.§6.5 세그먼트
11어드민고객 관리자동 태그 관리---가격민감형·충성고객·이탈직전·VIP후보·불만고객·탐색형·정기구매자·신규유망 태그의 자동 부여 조건 설정(예: 가격민감형 = 할인 적용 시에만 구매 패턴 3회 이상). 태그별 현재 해당 고객 수 표시. 태그 클릭 시 고객 목록 이동. 태그별 연결 자동화 시나리오 확인 가능.§10.1 자동 태그
12어드민고객 관리등급 관리---Bronze·Silver·Gold·VIP(Platinum) 등급별 승급 기준(온·오프라인 통합 누적 구매금액, 구매 빈도) 설정. 등급별 혜택(포인트 적립률, 무료배송 기준, 전용 할인율, VIP 매니저 배정 여부) 정의. 등급 전환 시 자동 발송 메시지 연결. 등급 하락 위험 감지 및 유지 혜택 발송 조건 설정. 현재 등급별 고객 분포 현황 표시.§9.2 등급 자동화
13어드민자동화 캠페인업셀/크로스셀 설정---AI 연관 상품 추천 알고리즘 선택 및 비중 설정(함께 구매 패턴·카테고리 연계·소셜 프루프). 무료배송 임박 유도 기준금액 설정(예: 50,000원 기준 시 잔여 금액 자동 계산 및 "N원만 더!" 배너 노출). 추천 상품 노출 시점(상품 페이지·장바구니·결제완료 화면·D+30분 발송) 및 각 시점별 추천 상품 수 설정. 소셜 프루프 문구 커스터마이징.§4.2 업셀
14어드민자동화 캠페인장바구니 이탈 복구---장바구니 담기 후 미결제 이탈 감지 조건 설정(이탈 판정 대기 시간 설정). 1차 발송(1시간 후): 발송 채널·메시지 내용·CTA 버튼 텍스트 설정. 2차 발송(24시간 후): 할인 쿠폰 포함 여부·쿠폰 금액(기본 5%)·메시지 내용 설정. 3차(48시간 후): 재고 부족 임박 알림 발송 여부 설정. 단계별 ON/OFF 토글 제공.§4.4 장바구니
15어드민자동화 캠페인구매 후 리마케팅 시퀀스---결제 완료 후 자동 발송 시퀀스 설정. D+1(리뷰 유도: 메시지 내용·포인트 보상)·D+3(사용법/활용 가이드: 연결 콘텐츠 URL)·D+7(연관 상품 추천: 추천 알고리즘 선택)·D+30(재구매 유도: 쿠폰 포함 여부) 각 단계별 발송 채널·타이밍·내용 설정. 상품 카테고리별 교체 주기 등록(화장품 60일, 사료 30일 등) 및 교체 주기 도래 시 자동 알림 설정.§4.3 리마케팅
16어드민자동화 캠페인재구매 리마인드---고객별 평균 구매 간격 자동 분석 후 예측 구매일 산정 기준 설정(구매 주기 N일 전 발송). 교체형 상품 카테고리별 교체 주기 설정 및 구매 시 "교체 주기 알림 받기" 옵션 제공 여부 설정. 계절·시기 기반 리마인드(작년 동일 시기 구매 상품) 활성화 설정. 발송 채널·메시지 내용·쿠폰 포함 여부 설정.§4.5 재구매 예측
17어드민자동화 캠페인이탈 방지 시퀀스 설정---이탈 위험 감지 조건 설정(30일 미로그인·이메일 오픈율 급감·구매 주기 2배 초과·NPS 6점 이하 등 항목별 ON/OFF). Step 1(감지 즉시): 발송 채널·개인화 혜택 메시지 내용·CTA 설정. Step 2(D+3): 재시도 채널(SMS·앱 푸시) 및 메시지 내용 설정. Step 3(D+7): CS 팀 자동 배정 여부·전화 상담 요청 템플릿 설정. Step 4(D+14): 최대 할인 오퍼 쿠폰 금액·유효기간·피드백 요청 메시지 설정. 각 Step별 ON/OFF 토글 및 전환 성공/실패 비율 모니터링 패널 포함.§4.6 이탈 방지
18어드민자동화 캠페인휴면 고객 재활성---60일·90일·180일·365일 각 휴면 구간별 자동 발송 메시지 내용·오퍼(쿠폰 종류·할인율)·발송 채널을 단계별로 설정. 각 구간 현재 해당 고객 수 실시간 표시. 365일 구간은 수신거부 전 최종 확인 메일 자동 발송 설정. 단계별 전환율 및 복귀 고객 매출 성과 확인 패널 포함.§4.7 재활성
18어드민자동화 캠페인VIP 자동화 설정---등급 달성 즉시 발송 축하 메시지 내용·채널 설정. 실버 이상 생일 쿠폰 자동 발급 기준(생일 N일 전·쿠폰 금액·유효기간) 설정. 골드 이상 전용 상담 채널 자동 배정 여부 설정. VIP 신상품 사전 공개 초대 발송 여부 설정. 등급 하락 위험 감지 시(갱신 기준 미달 예상) 유지 혜택 메시지 자동 발송 조건 설정.§4.8 VIP 관리
19어드민자동화 캠페인AI 발송 최적화 설정---고객별 과거 오픈 패턴 기반 최적 발송 시간 자동 계산 활성화 여부 설정. 채널 자동 선택(반응률 높은 채널 우선 발송) 활성화 설정. 고객별 발송 피로도 임계치(주 N회 초과 발송 차단) 설정. 가격 민감도 기반 오퍼 할인율 자동 조정 허용 범위(최소 1%~최대 30%) 설정.§4.9 AI 최적화
20어드민메시지 캠페인캠페인 목록---전체 캠페인 목록 상태별(진행중·예정·완료·중지) 조회. 캠페인명·대상 세그먼트·발송 채널·발송일·발송 건수·오픈율·전환율·매출 기여액 컬럼 표시. 캠페인 복사(재활용)·중지 기능. 완료 캠페인 상세 성과 리포트 이동. 기간·채널·세그먼트 필터 제공.§6 마케팅
21어드민메시지 캠페인캠페인 만들기---캠페인 생성 마법사(Wizard) 형태. ① 캠페인명·목적 입력 → ② 대상 세그먼트 선택(예상 발송 수 미리보기) → ③ 발송 채널 선택(알림톡·이메일·SMS·푸시·다중 채널) → ④ 메시지 내용 작성(동적 변수 {{고객명}}·{{상품명}} 삽입 지원) → ⑤ 발송 시간 설정(즉시·예약·AI 최적화 시간) → ⑥ 쿠폰 첨부 여부 → ⑦ A/B 테스트 버전 분리 옵션 → ⑧ 최종 확인 및 발송.§6.5 세그먼트
